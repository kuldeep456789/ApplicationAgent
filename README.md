
An autonomous AI agent that streamlines your job search by intelligently scraping job postings, analyzing requirements, matching your skills, and automating applications.

![Python](https://img.shields.io/badge/Python-3.11+-blue.svg)
![FastAPI](https://img.shields.io/badge/FastAPI-0.109+-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)


![img alt](https://raw.githubusercontent.com/kuldeep456789/ApplicationAgent/main/Screenshot%202026-01-02%20165121.png)


Automatically scrape jobs from LinkedIn, Indeed, and other platforms
Use Claude/GPT-4/Gemini to analyze job requirements and match with your skills
Generate customized cover letters for each application
Intelligently fill job application forms using Playwright
Track all your applications in one place
Beautiful Streamlit interface with glassmorphism design


### Windows

   scripts\windows\setup.bat
  scripts\windows\start_backend.bat
   

   scripts\windows\start_frontend.bat

### Linux/Mac

   chmod +x scripts/shell/*.sh
   ./scripts/shell/setup.sh
   
   ./scripts/shell/start_backend.sh
   
   ./scripts/shell/start_frontend.sh
